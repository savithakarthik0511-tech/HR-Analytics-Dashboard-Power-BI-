# HR-Analytics-Dashboard-Power-BI-

## 🚀 Project Overview

This project presents a **3-page HR Analytics Dashboard** built using Power BI to analyze workforce composition, employee performance, and training effectiveness.

The dashboard is designed to help stakeholders **make data-driven decisions** by transforming raw HR data into meaningful insights.

---

## 🎯 Objectives

* Understand employee distribution across departments, gender, age, and location
* Evaluate employee performance, engagement, and satisfaction
* Analyze training effectiveness, cost, and outcomes

---

## 📌 Dashboard Pages

### 1️⃣ Workforce Overview

* Total Employees, Average Age, Gender Distribution
* Employees by Department, State, and Age Group
* Provides a clear view of workforce composition

---

### 2️⃣ Performance & Engagement

* Average Performance, Engagement, and Satisfaction Scores
* Engagement vs Satisfaction (Scatter Plot Analysis)
* Rating Distribution and Work-Life Balance insights

🔍 *Key Insight:*
Distribution analysis was used instead of relying only on averages to uncover deeper patterns.

---

### 3️⃣ Training & Development

* Total Training Cost, Average Cost, Success Rate
* Training Cost by Program
* Training Outcome (Pass/Fail)
* Training Type (Internal vs External)

🔍 *Key Insight:*
Training effectiveness was analyzed by comparing cost and success rate.

---

## 🛠️ Tools & Technologies

* Power BI
* DAX (Data Analysis Expressions)
* Data Modeling
* Data Visualization

---

## 📊 Key Features

* Interactive dashboard with slicers (Department, Gender, Training Type, etc.)
* Dynamic KPI cards
* Drill-down and filtering capabilities
* Conditional formatting for better insights
